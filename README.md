# XML · Apuntes

🌐 **Web: https://apuntes-dam.github.io/xml-apuntes/**

Apuntes y ejercicios de **XML**: documentos, validación con DTD y XSD, XPath, XSLT y lectura desde programas. Todos los resultados de la teoría (errores, validaciones, consultas, transformaciones, programas) se han comprobado con analizadores reales, y cada solución de los ejercicios también.

Forma parte de [Practica los Lenguajes de Programación para 1º DAM y 2º DAM](https://apuntes-dam.github.io/apuntes-lenguajes/).

## Cómo está hecho

Web estática con [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) publicada con GitHub Pages: el workflow `.github/workflows/pages.yml` construye y despliega al hacer push a `main`. En local:

```bash
pip install mkdocs-material
mkdocs serve
```

Las soluciones modelo están cifradas; solo se ve el comienzo de cada una.
