## Antes de empezar: qué debes dominar

* XML es un metalenguaje: define las reglas, no las etiquetas.
* Elemento raíz único, etiquetas cerradas y bien anidadas, atributos entre comillas.
* Entidades (`&lt;`, `&amp;`) y secciones CDATA.
* Espacios de nombres: `xmlns` y prefijos.
