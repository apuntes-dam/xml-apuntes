# U2 · Validación

Comprobar que un documento respeta una estructura: la diferencia entre estar **bien formado** y ser **válido**, las **DTD** (elementos, atributos, `ID` e `IDREF`) y **XML Schema** (tipos, restricciones, `minOccurs` y `maxOccurs`).

## Teoría

* [2.1 Bien formado y válido](01-valido.md)
* [2.2 DTD](02-dtd.md)
* [2.3 XML Schema (XSD)](03-xsd.md)
* [2.4 DTD frente a XSD](04-comparar.md)

## Antes de empezar: qué debes dominar

* Bien formado frente a válido.
* DTD: `ELEMENT`, `ATTLIST`, cardinalidad `? * +`.
* XSD: tipos simples y complejos, restricciones, `sequence` y `choice`.
