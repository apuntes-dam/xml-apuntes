# U4 · XML en la práctica

Tres situaciones muy habituales en el día a día: convertir entre **XML y JSON**, analizar documentos enormes con **SAX** en vez de cargar todo el árbol, y el problema más típico al consultar con XPath un documento que usa **espacios de nombres**.
